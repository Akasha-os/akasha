# Akasha

**Not a chatbot. A second brain.**

Akasha captures your documents, activity, and biometrics into a living knowledge graph.
It surfaces what matters before you think to ask — and acts on your behalf when you tell it to.

Self-hosted · Open source · MIT licensed

### What Akasha does

```
You read an article          → Akasha connects it to your projects
You attend a meeting         → Akasha extracts decisions and open loops
Your HRV drops for 3 days    → Akasha notices and adjusts your schedule
You return to a project      → Akasha restores your context automatically
```

### Get started

```bash
git clone https://github.com/akasha-os/akasha
cd akasha
cp .env.example .env
docker compose up
```
